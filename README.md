# Ejercicio CV Bootstrap

Proyecto de currículum vitae desarrollado con HTML y Bootstrap.

## Descripción

Este proyecto toma la información base del archivo `borrador.html` y la presenta en `index.html` con una estructura responsive utilizando Bootstrap.

El CV incluye:

- Presentación personal.
- Experiencia laboral.
- Educación.
- Habilidades adicionales.
- Enlaces de contacto a GitHub y LinkedIn.

## Tecnologías utilizadas

- HTML5
- Bootstrap 5
- Node.js
- npm

## Dependencias

El proyecto utiliza las siguientes dependencias instaladas con npm:

- `bootstrap`
- `prompt-sync`

## Cómo usar

Instala las dependencias si no existen en tu equipo:

```powershell
npm.cmd install
```

Luego abre el archivo `index.html` directamente en el navegador.
